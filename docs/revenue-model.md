# MusicianSearch — Revenue Model

## Model: Freemium Subscription

### Free tier
- Create a profile, appear in limited search results.
- Limited number of searches/profile views and new conversations per month.
- Standard (non-boosted) visibility.

### Paid tier (subscription — monthly/annual)
- Unlimited search, filtering, and messaging.
- Advanced filters (e.g. multi-instrument, precise availability matching).
- Visibility boost / priority placement in others' search results.

### Verification badge
- Available to both tiers — identity verification is a safety requirement, not a paywall item. The badge itself is free; the paid tier gets usage benefits (search/messaging limits), not the badge.

## Explicitly Rejected for v1

- **Pay-per-contact / credits system** — rejected because it feels transactional and closer to dating-app mechanics the product is deliberately avoiding.
- **Marketplace commission** — not applicable, since v1 has no paid-gig/payment flows between users (see `requirements.md` non-goals).

These could be revisited in a later phase if paid gigs are ever introduced as a feature.

## Open Items

- Specific free-tier limits (e.g. exact message/search caps) not yet set.
- Paid-tier price point not yet set.
